# Customer Shopping Behavior Analysis
## 📌 Overview
### This project analyzes customer shopping behavior using transactional data to uncover insights into spending patterns, product preferences, customer segments, and      subscription behavior. The analysis supports data-driven business decisions and strategic planning.
### The workflow covers end-to-end analytics: Python data processing, SQL analysis, Power BI dashboarding, reporting, and presentation creation.
--------------------------------------------------------------------------------------
## 📊 Dataset
- ~3,900 transaction records  
- 18 columns  
- Includes:
  - Customer demographics (Age, Gender, Location, Subscription Status)
  - Purchase details (Item, Category, Amount, Season, Size, Color)
  - Behavior metrics (Discount usage, Purchase frequency, Review ratings, Shipping type)

---

## 🛠️ Tools & Technologies
- **Python:** Pandas, NumPy (EDA & data cleaning)  
- **SQL:** PostgreSQL / MySQL / SQL Server (analysis queries)  
- **Visualization:** Power BI  
- **Reporting:** Analytical report  
- **Presentation:** Gamma

## ⚙️ Project Workflow

### 1. Data Loading & Exploration (Python)
- Imported dataset using pandas  
- Checked structure and summary statistics  

### 2. Data Cleaning & Preparation
- Handled missing values  
- Standardized column names  
- Feature engineering:
  - Age groups
  - Purchase frequency
- Removed redundant columns  

### 3. Database Integration
- Loaded cleaned data into SQL database  

### 4. SQL Analysis
Key business questions addressed:
- Revenue by gender  
- High-spending discount users  
- Top-rated products  
- Shipping type comparison  
- Subscriber vs. non-subscriber behavior  
- Discount-dependent products  
- Customer segmentation (New, Returning, Loyal)  
- Revenue by age group  
- Top products per category
